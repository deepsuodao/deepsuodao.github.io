给家庭财务做一次年度审计（附自检表）

深索道的书房。桌上放着一沓打印好的纸。安德路先到了，格林格·金晚了几分钟，进门的时候手里也拿着一张纸。

安德路： 金姐，你手里拿的什么？

格林格·金： （坐下）我儿子学校的年度体检表。刚才路上顺便填了。

深索道： 巧了。我今天也让你们填一张表。

安德路： 什么表？

深索道： 你家财务的年度体检表。八个问题，15分钟，不查账户，不算公式，凭感觉打钩。

格林格·金： （看了一眼）有意思。跟学校那个体检表一样——不是让你得满分，是让你知道哪些指标该复查了。

深索道： 那开始。第一个问题，关于保障金。

Q1：不算股票、不算房产，只算低风险、一周内可变现的金融资产（定期存单、国债、理财等），能覆盖你家几个月的固定支出？

→ 36个月以上（10分）

→ 12-36个月（7分）

→ 6-12个月（4分）

→ 不到6个月（1分）

安德路： 12到36个月。7分。

格林格·金： 36个月以上。10分。

深索道： 下一个。

Q2：这笔保障金有没有被动用过的迹象？

→ 独立账户，从未动过（10分）

→ 动过但已经补回来了（7分）

→ 最近被借走了一部分还没还（3分）

→ 已经被全部挪用了（0分）

安德路： 独立账户，没动过。10分。

格林格·金： 同上。10分。

深索道： 第三个，关于负债和信用。

Q3：你有没有新增任何形式的担保、连带责任或隐性借贷？

→ 完全没有（10分）

→ 有信用卡或花呗分期，但每月全额还清（7分）

→ 为他人提供了担保（3分）

→ 有网贷或借呗未还余额（1分）

安德路： 没有。上次那个担保我没签。10分。

格林格·金： 我有企业连带担保——是公司架构层面的，不是我个人的。但严格来说算有。7分。

安德路： 企业连带也算？

格林格·金： 算。如果你以个人名义为公司融资担保，公司出问题，银行会找你个人。

Q4：你清楚自己目前总负债的利率吗？

→ 完全清楚，且大部分是固定利率（10分）

→ 大概知道，最近没关注（6分）

→ 不太清楚，凭感觉还（3分）

→ 完全不知道（0分）

安德路： 房贷利率3%，清楚。10分。

格林格·金： 我有浮动利率的贷款，每年关注一次。10分。

深索道： 第五个，关于应急金——随时能取的活钱。

Q5：不算理财、不算股票，只看活期存款和货币基金，如果你明天急需3万元，最快几天能拿出来？

→ 当天就能（10分）

→ 3天内（8分）

→ 一周内（5分）

→ 一个月以上或拿不出来（1分）

安德路： 3万的话，活期和货基就够了。当天。10分。

格林格·金： 当天。10分。

Q6：你的资产里有锁定期产品吗？最近半年到期的有多少？

→ 没有锁定期产品（10分）

→ 有，但金额和到期时间清楚（7分）

→ 有，且金额较大、分散在不同到期日（4分）

→ 有大笔资金被锁定超过一年以上（1分）

安德路： 没有。10分。

格林格·金： 有一些定存和私募，到期时间标在日历上。7分。

深索道： 第七个，很多人会卡住。

Q7：过去一年，你家的结构有变化吗？

→ 没有变化（10分）

→ 有变化，但已经更新了所有相关文件（7分）

→ 有变化但还没更新文件（3分）

→ 正在进行重大变化（离婚或继承或企业重组）（0分）

安德路： 没有变化。10分。

格林格·金： 没有。10分。

深索道： 第八个，关于纪律。

Q8：你的实际持仓，和你计划的比例偏离了多少？

→ 完全按计划执行，偏离不超过5%（10分）

→ 有些偏离，但不超过15%（6分）

→ 偏离超过15%，但知道为什么（3分）

→ 不知道自己的计划是什么，买到哪算哪（0分）

安德路： 我可能偏了10%左右。6分。

格林格·金： 我有一笔配置是机械执行的，一年只调两次。10分。

安德路： 来，算分。我：7+10+10+10+10+10+10+6 = 73分。

格林格·金： 我：10+10+7+10+10+7+10+10 = 74分。

安德路： 你74分？我以为你会满分。

格林格·金： 74分已经不错了。企业担保扣了3分，锁定期产品扣了3分。这两个东西不是"做错了"，是需要管理。满分的人有两种——一种是确实完美，一种是不敢对自己诚实。

安德路： （看了看自己的分数）73分，安全的线过了。但我差在哪？

深索道： 73分，安全的线过了。差在纪律——融资比例偏了，回头看一下就行。

安德路： 金姐，你这个74分，平时的管理成本高吗？

格林格·金： 不高。这些检查大部分不是我自己做的。有人替我盯着。

安德路： （看了一眼深索道）你说的"有人"，是指？

格林格·金： 我没有私家智囊这样一个人。但我有财务顾问、有保险经纪、有律师——凑在一起做这件事。你能一个人搞定这些，其实比我有效率。

安德路： 那普通读者也想做这个测试呢？

深索道： 这张表就在这里。八个问题，15分钟，每年做一次。截图保存。

安德路： 分数低的人怎么办？

深索道： 不用慌。分数低不是因为你做得差，是从来没人让你做过这件事。下一步怎么做，看哪个维度分最低——

→ 保障金分低 → 优先补充低风险储备（定期存单、国债、理财）

→ 负债分低 → 厘清所有债务和担保

→ 应急金分低 → 留够随时能取的活钱

→ 家庭结构变了 → 更新相关法律文件

→ 纪律分低 → 回到最初的计划，先别动

格林格·金： 我补充一句。这张表的意义不是让你焦虑。我儿子学校那张体检表，上面写的也不是"你得满分才能上学"。它写的是"这几项需要复查"。知道自己哪项需要复查，就已经完成了一大半。

家庭财务自检表（完整版）：

结果对照：

→ 70-80分：安全 ✅

→ 50-69分：关注，有1-2条接近预警 ⚠️

→ 30-49分：预警，需要系统梳理 🔴

→ 低于30分：紧急，建议尽快做完整审计 🚨
