对话 · 第三十一篇

家庭税务健康体检：境内外收入合规指南

时间：一个工作日的下午
地点：公司会议室，白板上半边画着"家庭税务全景地图"，半边贴着一张从税务局官网打印的通告摘要
人物：深索道 – 首席策略师 ／ 格林格·金 – 投资公司创始人 ／ 安德路 – 量化研究员 ／ 老陈 – 资深税务师（特邀嘉宾）

第一幕 · 一封"通知单"和两个新政

安德路推门进来，手里不止有年度汇算的材料，还多带了一份剪报——严格说是手机截图，标题冷冰冰的：

证监会等八部门《综合整治非法跨境证券期货基金经营活动实施方案》——全面取缔非法跨境展业，存量账户"只许平仓出金、不许加仓入金"。

安德路深总、金姐，老陈——你们看到了吧？富途、老虎、长桥这周全发了公告：6月12日起，内地居民存量账户暂停新开仓、加仓、入金，只许卖出平仓出金。八部门联合，经国务院同意。

格林格·金（抬眼）这不是突然的。从2022年底第一轮整治算起，这条路一直在收窄。只是这次规格更高、链条更全——营销招揽、开户引流、交易指令跨境传输、平台提供便利，全链条禁止。

老陈（把手机翻过来，屏幕上是另一条信息）更直接的，是金税四期这边。

他从公文袋里抽出两张纸，一张是自然人电子税务局的"境外所得填报提示"弹窗截图，一张是税务总局公开的口径摘要：

  • 金税四期已经打通税务、银行、外汇、出入境、不动产等数据通道，"一人式"档案把你的账户流水、购汇记录、出入境轨迹交叉比对。
  • CRS（共同申报准则）中国已与120+国家和地区交换金融账户信息——境外银行、券商、保险、信托的余额和收益，会定期自动传回。
  • 结果就是一句大白话：境外收入"藏不住"，也不靠你自觉申报——系统自己会说话。

安德路所以……那八部委的新规，加金税四期，意思就是——以前那种"开个境外账户炒美股/拿分红不报"的路子，现在两头都被焊死了？

老陈对。一句话：出境的购汇、入金被严管；入境的收入信息被自动交换。你个人能做的，不是"找漏洞"，是把申报做干净。

深索道今天安德路的截图，其实是很多家庭的缩影——不是他们想逃税，是他们不知道规则已经变了，还活在五年前的世界里。

第二幕 · 家庭税务的"全景地图"（含金税四期与八部委新规）

深索道走到白板前，更新了全景图：

家庭税务全景地图（2026年版）

一、收入端税种

  1. 个人所得税（工资薪金、劳务、稿酬、经营所得）
  2. 投资收益（股息/红利/股权转让/资本利得）
  3. 租金收入

⚡ 新增现实：境外所得（港股分红、美股收益）→ CRS自动交换 → 必须申报

二、资产端税种

  1. 房产交易（增值税、契税、个税）
  2. 证券交易印花税

⚡ 注意：八部委新规后，境外券商"非法跨境展业"账户→只能平仓出金→不能再当"常态投资通道"用

三、跨境/身份层

  1. 税务居民身份认定
    中国：有住所（户籍/家庭/经济利益中心）OR 183天/年
    双重居民 → 税收协定"加比规则"破僵局
  2. CRS信息交换 + 金税四期数据穿透
  3. 遗产税/赠与税（国内未开征，但移民前要算清对方规则）

四、特殊雷区

  1. 个体户/小企业主：公私混同（公司货款走股东私卡、费用不实报销）
  2. 慈善捐赠：可抵扣，但有比例与要件
  3. 数字资产/加密：政策未明，但CRS已在扩围申报

老陈这张图最该记住——金税四期管数据闭环，八部委管通道合法性，CRS管信息透明度。三条线合起来，把"境外=盲区"这个幻觉彻底灭了。

第三幕 · 税务处理的"八条铁律"

深索道老陈，请你给安德路把原则钉死。

老陈在白板写下：

家庭税务八条铁律

1. 依法纳税是底线

→ 业务发生后必须遵从；稽查函/预警弹出时，先别慌，先看它是"提示"还是"通告"

2. 事前筹划是窗口

→ 只有在业务未发生前（架构、身份、合同、账户拆分），才能合法利用优惠/地区差异
→ 事后补救≠筹划，叫"补窟窿"，代价翻倍起

3. 重要性原则

→ 抓大放小：工资/分红/股权转让/境外所得 >> 小额副业/零碎兑换

4. 成本效益原则

→ 省税1000块别花3000块咨询费；省税100万才值得做架构

5. 全局性原则

→ 个税减了，别忘了影响征信/社保基数/企业往来；按下葫芦会浮起瓢

6. 风险隔离原则

→ 用有限公司/个体户/信托把"经营风险"和"家庭生活钱"隔开
→ 公私混同是金税四期最爱抓的典型

7. 动态调整原则

→ 税法/稽查重点/地区优惠会变（海南15%可能，新加坡政策也可能收）
→ 每年至少一次"税务体检"

8. 专业的事交给专业的人

→ 具体申报、备案、协定待遇申请→找注册会计师/税务师
→ 我们可以给框架和原则，但不替你签字

安德路第六条"风险隔离"——你是指范蠡那种"散财"？

老陈不是散财，是分账。范蠡把财富分三份：能亮出来的、能搬走的、能藏善根不动的。

现代人最简单的版本——

家庭生活费：工资走个人账户，干净报税。

经营/投资：走公司对公或规范个体户。

保障层：保险/国债/应急金（不掺经营风险）。

深索道这跟我们五格结构图完全一致——堡垒账户、锋利账户、保障金——税务上也必须"分格子"，不然一锅粥，稽查一来全锅都悬。

第四幕 · 国内案例：CRS + 税务居民身份（183天/住所/加比规则）

安德路那CRS到底怎么"抓人"？给我一个活生生的。

老陈我讲两类，都是今年扎堆的。

案例A：境外分红漏报，CRS送上门

一位企业主早年设了BVI壳公司持有境外工厂股权，每年分红打去境外私人账户，从没在国内申报。

今年CRS交换后，税务机关拿到账户的分红明细、余额变动，直接发《涉税事项通知书》——补缴个税（20%档）+滞纳金，因为"主动来"姿态好，没走顶格罚款。

他原话："以前觉得离岸架构是安全伞，现在知道是定时组件。"

案例B：香港永居，但内地户籍+家庭+企业都在内地 → 仍是中国税务居民

深圳一位拿香港永居7年的老板，内地户口一直没销。

CRS把他的香港账户（约2800万金融资产）信息传回内地→补税+滞纳金470万。

关键误区：他以为"有香港身份证=香港税务居民=不用向内地报"。

但内地税法认的不是卡片，是"习惯性居住"：户籍、家庭、经济利益中心在不在内地？

答案全在内地→中国税务居民→全球所得要报。

老陈在白板写了三条硬标准：

你到底是不是中国税务居民？

  1. 有住所 = 因户籍/家庭/经济利益关系在境内习惯性居住
    → 只要①成立，无论你拿什么海外ID，全球所得都要报
  2. 无住所，但一个纳税年度内累计住满 183天
    → 也认定为居民（全球报税）
  3. 双重居民（两边国内法都认你）
    → 走税收协定的"加比规则"（Tie-Breaker）：
      - 先比永久性住所 → 重要利益中心 → 习惯性居所 → ……
      - 核心：你的生活/事业/资产重心在哪，你最终就归属哪边

安德路所以"移民不移居"的人——每年回内地超183天、老婆孩子在内地、公司内地——

老陈——基本铁定为中国税务居民，香港ID不帮你躲内地全球征税。想合法用境外低税，要先走身份+住所+天数的全盘规划，不是买张卡就完事。

第五幕 · 国际案例：规则越来越紧——新加坡、美国、DTA

安德路国际上呢？大家都说"钱放新加坡就安全"。

老陈新加坡属地征税确实友好：本地产生/汇入的收入才课税。但两点冷水——

  1. 中新《避免双重征税协定》（DTA）有反滥用条款（PPT）：纯导管壳、没商业实质，协定优惠会被拒。
  2. 新加坡对家族办公室13O/13U门槛、经济实质、透明化一路收紧——不是"随便开个壳就进"的年代了。

格林格·金美国那边呢？

老陈美国更直白——公民/绿卡=全球征税+FATCA，放弃国籍还有弃籍税/退出税。很多家庭在拿EB-5或绿卡前，没做税务建模，落地才发现"境外母公司分红"会变成持续头痛。

深索道所以这三个国家拼起来，给家庭财富一个很冷但很重要的结论：

税务居民身份，是现代家庭财富里最贵的"隐藏变量"。

你以为你在选生活方式，系统在算你的纳税归属。

选之前要建模，选之后要申报一致——别让身份变成一把钝刀，慢慢割你。

第六幕 · 专项警示：个体户/小企业主的"公私混同"

安德路我身边好多朋友自己开公司，钱进出私卡……

老陈（语气直接但不训人）：

金税四期最喜欢这种样本：对公货款进股东私卡=视同分红；公司费用列支家庭消费=偷逃；私户代收=隐匿收入。

他举了最常见的三颗雷：

  1. 货款走私卡
    → 账面"存货还在"，但私卡一大笔进账 → 税务局要求解释为"个人所得"→20%个税+滞纳金
  2. 家庭车/旅游/学费贴进公司成本
    → 一经穿透，不仅要调增应纳税所得，还毁"经营真实性"形象
  3. "备用金"常年挂账不还
    → 超期视同分配

深索道对应五格图的说法很简单——堡垒账户归家庭，锋利账户归投资，别让公司账户当海绵吸生活支出。

第七幕 · 稽查应对实操：收到通知书后怎么办

安德路万一……我是说万一，真的收到税务通知书，第一步该干嘛？不能慌，但也不能拖。

老陈这个问题问到点子上了。我给你一个三步法，按这个来，90%的情况都能平稳落地。

第一步：别动，先识别（24小时内）

老陈收到通知书/预警弹窗，先别急着"补税"或"找关系"——

先识别它是哪一种：

  • 提示类（《纳税风险提示》/系统弹窗）→ 低危险 → 核对数据，有误就申诉，无误就补报
  • 询问类（《税务事项通知书》/《询问通知书》）→ 中危险 → 限期回复（通常5-15天），找税务师一起准备材料
  • 稽查类（《税务稽查通知书》）→ 高危险 → 立即停止自行补税，先请专业顾问评估，再决定策略

格林格·金很多人犯的第一个错误——收到提示类弹窗，吓得直接把钱转走或乱填数据，反而触发"人工复核"。

老陈对。提示≠处罚，它只是系统觉得"你这数据有点怪，来解释一下"。你解释得清楚，它可能直接消掉。

第二步：材料归集（3-7天）

安德路那如果我确实需要补税，或者要解释，材料怎么准备？

老陈分三类，按这个清单准备——

第一类：收入凭证

  • 工资：个税APP截图（综合所得年度汇总）
  • 股息红利：上市公司分红公告 + 证券账户流水
  • 股权转让：股权转让协议 + 付款凭证 + 原值凭证（出资证明/评估报告）
  • 境外收入：境外券商/银行出具的年度对账单（英文版需翻译公证）

第二类：成本/扣除凭证

  • 专项附加扣除：个税APP截图（已填报项）
  • 股权转让成本：原始出资凭证、合理费用发票（中介费/评估费）
  • 经营费用：对公账户流水 + 发票（注意：家庭消费不能混进来）

第三类：身份/协定凭证（中高端读者重点）

  • 税务居民身份证明（如适用税收协定）
  • 境外纳税凭证（避免双重征税）
  • 税收协定待遇申请表（如适用DTA优惠税率）

第三步：主动申报 vs. 被动稽查（选择策略）

深索道这里有个关键判断——你是"主动来"，还是"被叫来"？

老陈差别巨大——

主动申报（自己在汇算时补报，或在收到提示后主动更正）
- 通常只补税 + 滞纳金（每日万分之五）
- 罚款可以免（首违不罚/主动纠错）
- 征信不受影响

被动稽查（税局主动立案稽查后查出）
- 补税 + 滞纳金 + 罚款（少缴税款的50%~5倍）
- 严重情况：列入税收违法"黑名单"、限制高消费、影响出入境
- 企业主还可能牵连企业经营资格

格林格·金所以老陈你一直说"主动合规的成本 < 被动稽查的代价"——这就是数学。

老陈对。我经手案例里，主动来补的，最惨也就是补税+滞纳金（相当于年化约18.25%）；被稽查的，罚款翻倍是起步价。

[中高端补充] 已经"公私混同"的整改路径

安德路那如果……我是说如果，我公司货款已经进了私卡，现在怎么办？

老陈别慌，但有且只有一条路——主动整改，别等稽查来敲门。

整改三步法：

第一步：停止新增（立即）

  • 对公收入一律进对公账户
  • 已进私卡的公款，暂停再进

第二步：分类清理存量（3-6个月内）

  • 股东借款：补签借款合同 + 补计利息（按银行同期利率）+ 制定还款计划
  • 视同分红：如果私卡资金确实无法归还，主动按"股息红利"20%申报补税 + 滞纳金（别等稽查来定"偷税"）
  • 费用不实：把已列支的私人消费调出，重新做企业所得税汇算清缴

第三步：未来隔离

  • 开规范个体户/有限公司，把经营收入和家庭收入彻底分开
  • 参考五格结构：堡垒账户（家庭）≠ 锋利账户（投资/经营）

深索道翻译成一句话——现在主动补，成本是可计算的；等稽查来，成本是不可控的。

[中高端补充] 已设境外架构的"平移"而非"撤回"

安德路那如果我已经设了BVI公司、境外账户，现在一定要"撤回来"吗？

老陈不一定。"平移"比"撤回"更聪明——

平移架构三原则：

1. 补商业实质

  • 境外公司不能再是"壳"——要有实际办公地址、雇员、决策会议记录
  • 例：新加坡家族办公室13O要求5000万新币资产 + 2名投资专业人士

2. 补合规申报

  • 境外公司关联交易 → 要有关联交易申报
  • CRS已交换，主动申报才能拿"合规身份"

3. 平移而非一刀切撤回

  • 撤回 = 视同清算，可能触发20%个税 + 外汇审批
  • 平移 = 保留架构，补实质、补申报，变"风险伞"为"合规平台"

深索道翻译成一句话——离岸架构不是原罪，没有商业实质的离岸架构才是原罪。

第八幕 · 工具箱引导与收束金句

老陈盖上文件夹，说了两句话：

老陈（收束①）：
> 合规为盾，架构为桨，时机为风。 盾不牢，桨越快翻得越狠；风不借，舟只能原地打转。

深索道（收束②）：
> 金税四期+CRS+八部委新规——这三件事合起来只有一条活路：把税务从"侥幸"抬升为"系统配置"。

格林格·金「私家智囊」工具箱 → 「八问自检表」——先做一份自我排查：

税务健康三问（自查版）：

  1. 境外账户：有没有境外券商/银行/保险账户，从未在个税APP填报？
  2. 公私边界：公司货款是否进过股东私卡？公司费用是否列支过家庭消费？
  3. 身份清晰度：你的税务居民身份算过吗（183天/住所/双重居民）？

三问中只要有一题答"是"，建议找税务师做一次完整体检。税务健康体检工具即将上线，届时可在工具箱中找到。

具体申报、协定待遇、离岸架构合规审查——找你的税务师。
我们只给你框架、原则、风险提示和体检表。

安德路（走到门口，回头，终于笑了）：所以……今天不是让我交更多税，是让我别等稽查来敲门？

老陈对。主动合规的成本 < 被动稽查的代价，这笔账你算得清。

钱怎么传？资产怎么交？机制怎么设？

文中的金句

  • 境外收入"藏不住"，也不靠你自觉申报——系统自己会说话。
    → 应用：今年汇算时，主动检查境外账户是否已申报。
  • 金税四期管数据闭环，八部委管通道合法性，CRS管透明度——把"境外=盲区"的幻觉灭了。
    → 应用：不要幻想"境外账户是盲区"，系统已经在看。
  • 拿了海外ID ≠ 自动变海外税务居民；习惯性居住/家庭/经济利益中心才是内地认定的锚。
    → 应用：做移民决策前，先做一次税务居民身份测算。
  • 税务居民身份，是家庭财富里最贵的"隐藏变量"。
    → 应用：把你的身份、居所、天数算清楚，别让身份变成钝刀。
  • 合规为盾，架构为桨，时机为风。
    → 应用：先建合规基础，再做架构设计，最后等时机成熟。
  • 主动合规的成本，永远小于被动稽查的代价。
    → 应用：有疑问就主动补报，别等通知。
  • 省税靠制度设计，不靠瞒。
    → 应用：用五格结构图把家庭财务"分格子"，税务自然清晰。
