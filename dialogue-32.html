对话 · 第三十二篇

传什么，比传多少钱更重要——家族传承的四层功课与三个阀门

📌 核心结论

传钱，三代必败；传资产，一代可守；传机制，才可久。四层功课（资产/能力/价值观/关系）加三个阀门（健康/能力/结构）——阀门没就绪，舵不交。出海小微主的传承第一课不是接班，是解绑。信心来自机制，传承就是把这个机制交到下一代手上。

时间：一个秋日下午
地点：深索道书房，安德路带了一份《胡润财富报告》的截图——"中国未来10年将移交18万亿财富"
人物：深索道 – 首席策略师 ／ 格林格·金 – 投资公司创始人 ／ 安德路 – 量化研究员

第一幕 · "爸，你什么时候交给我？"

安德路把手机放下，话锋一转：

安德路深总，我上周参加一个饭局，坐我旁边一位做制造业的老周，55岁，企业年利润两千万上下。他儿子28岁，英国读完书回来，坐下第一句话就问："爸，你打算什么时候交给我？"

格林格·金老周怎么答？

安德路老周说"再等等"。但他表情……像嘴上说再等等，心里在说"我也不知道"。

深索道（点头）老周的困境，是所有第一代创造者的困境——他知道企业是他一手建起来的，但他对"交出去之后会怎样"没有把握。而这种不确定，恰恰说明他从来没把传承想透。

安德路什么意思？

深索道大多数人理解的传承是——"我把钱传给你。" 但真正的问题是：你传给他的，是钱？是资产？还是一套让钱继续生钱、且不把家拆散的机制？

第二幕 · 传钱 / 传资产 / 传机制——三个答案，三种结局

深索道在白板写下一行：

传承三答案：传钱 ？| 传资产 ？| 传机制 ？

格林格·金我见过太多"传钱"的家庭。老周如果把两千万利润直接分给儿子——

安德路怎么不好？儿子不就有钱了？

格林格·金两千万现金，第二年碰上个"稳赚不赔的项目"，第三年亏掉一半。或者儿子觉得"反正我有钱"，消费升级滑梯启动——箕子的象牙筷子。三年后钱没了，企业也被抽干了。

深索道这叫"传钱"——只传结果，不传系统。结局是统计学意义上的必然：钱会流向能管理它的人，如果你的孩子没学会管理，市场会替你教他——用归零的方式。

安德路那"传资产"呢？

深索道传资产，就是传"钱生钱的载体"——企业股权、厂房设备、投资性房地产、投资组合。老周把企业51%股权过户给儿子，让他当董事长。

安德路这不是更好吗？至少生产线、品牌、客户关系都还在。

深索道更好，但还不够。因为你传给他的是"经营责任"，不是"管理能力"。如果儿子没经过训练就接盘，碰上行业下行、利率上行、一次错误扩产——企业股权反而从"资产"变成"负债"，因为刚性成本和担保不会因为你换了董事长就消失。

格林格·金所以最高一层是——

深索道传机制。 三层意思：

  1. 资产配置机制（五格结构图、保障金底线）——不管谁当家，钱都按规则摆
  2. 决策机制（家族议会、章程、重大事项保留给老周或信托保护人）
  3. 价值观机制（家风、低调、不炫富、钱是工具不是奖杯）

传钱 = 给他鱼。传资产 = 给他渔场。传机制 = 给他"渔场的管理制度+不准拆底线的规矩"。第三种，即使第二代平庸，系统也能运转。

安德路所以老周真正该传给儿子的，不是股权，是——

格林格·金是"让股权继续生钱的一套规则"，加上"儿子要经过验证才有资格掌舵"。

第二幕·补 · 小微出海主的传承第一课

深索道但还有一种更棘手的情况——很多做海外工程、跨境电商、一带一路沿线贸易的小企业主。他们的问题不是"钱太多怎么分"，而是人、事、钱还绑在同一根手指上。

安德路什么意思？

格林格·金这类企业主自己就是CEO、销售总监、担保人三位一体。海外项目靠他个人信用拿单，国内授信靠他个人无限连带，回款周期半年起步。一旦他生病、犹豫、或者想退休，整个链条就断了——海外应收账款还在天上飞，国内的担保链已经咬喉。

深索道对这类家庭，传承的第一课不是"接班"，是解绑。三件事必须在他还在位时做完：

  1. 个人担保退出路线图——用项目回款、信用保险、国企保理，逐步替换"老板签无限连带"
  2. 海外业务实体化——别再"国内公司+老板护照"混跑，至少在境外做项目公司、在地化账目
  3. 现金流仪表盘——把海外回款、税费、汇兑损耗做成可审计的视图。你能看到，机制才存在

安德路所以，他们连"传资产"都谈不上，得先"把资产上背负的各种负债从自己身上解下来"？

格林格·金对。否则你传的不是企业，是一颗还没拆引信的担保弹。

第三幕 · 第一层：资产的传承——股权、控制权与"不断流"

安德路那如果走"传资产"这条路，股权怎么安排才算稳妥？

格林格·金三个硬原则——

原则一：控制权与收益权可分拆。

股权可以设成双层结构：A类股（每股投票权为B类股的N倍，如10:1），归老周或信托保护人保留；B类股（分红权，给儿子）。不是不交，是先交"收益"，不交"拍板权"。

原则二：企业是"资产"，不是"提款机"。

设一道硬性防火墙：家族年度从企业支取的上限——比如净利润的20%，其余必须留作公积金、再投资、偿债。这就是晋商号规的现代版。

原则三：婚变防火墙。

婚前协议、股权不列入婚后共同财产的约定、境内信托隔离——不是不信任儿媳女婿，是保护企业不被一次离婚切成两半。

深索道说白了——你传给下一代的"资产"，必须以"不影响资产继续生钱"为前提。一旦资产被抽出去消费，传承就退化成"传钱"。

传钱本身也有税务成本——赠与不免税（受赠方契税3%），继承虽无"遗产税"但过户需公证费，股权转让按20%财产转让所得计税。这些成本要在"传"之前就算清楚，不然传出去的金额会打折。

第四幕 · 第二层：能力的传承——不是"教育"，是训练体系

安德路但万一儿子就是不擅长经营呢？

格林格·金那你就更不能传股权了。能力的传承，不是送他去读个MBA，是三步验证——

深索道在白板写：

能力验证三步（必须在"交舵"之前完成）

Step 1：小规模试错
→ 给他管一个小产品线、一个门店、一笔500万的卫星账户
→ 允许亏，但设止损线（比如-15%）
→ 看他在压力下做决策，而不是听他说"我有vision"

Step 2：跨部门轮岗
→ 生产→采购→销售→财务，各至少3个月
→ 让他知道企业不是"品牌+订单"，是"现金流+供应链+人"

Step 3：反向答辩
→ 让老臣、CFO、外部董事向他提问
→ 他必须答出：下季度现金流怎么排、最大风险在哪、如果丢了一个大客户怎么活
→ 过了这一步，才谈"接班"

安德路所以如果不过这三步——

深索道——老周就该用职业经理人，让儿子先做股东、董事长（战略监督），不当CEO（日常操盘）。

第五幕 · 第三层：价值观与家风——《智囊》的传家智慧

安德路但能力之外……价值观怎么传？这东西不是太虚了吗？

深索道不虚。价值观决定的是"底线在哪"——底线一破，再好的资产也能被败光。

他翻开《智囊》，讲了两条：

第一条：季文子相三君——"妾不衣帛，马不食粟"。

季文子身为鲁国执政，家属过俭朴，旁人觉得寒酸。他说"吾以德荣国，不求华服"。翻译成家族语言：你们家对外越低调，第二代越少被消费竞赛绑架。

深索道老周的儿子如果从小开好车上学、朋友圈晒的是高端餐厅和旅行——"象牙筷子"已经从第一天摆上了。家风的第一条，不是"多读书"，是"财富不用来装饰身份"。

格林格·金用约束函数的语言来说就是——家族成员的显性消费增长率，应当小于等于企业净利润增长率。 违反它，就在侵蚀保障金底座。

第二条：祭仲论都城——"都城过百雉，国之害也"。

城墙太高=僭越=危险。翻译成家族：过早把第二代推到"高墙"上——富豪榜、媒体曝光、社交圈顶层——等于给家族树敌。低调是最强的护城河。

安德路所以《智囊》给传承的答案不是"怎么藏钱"，是——

深索道怎么让你的家族在财富面前保持"无害、可信、可预测"——这才是能传三代的东西。

第六幕 · 第四层：关系的传承——家族治理三件套

安德路但最难的是——兄弟之间、妯娌之间、父子之间，钱一搅进去，关系就变形。

格林格·金对。所以传承的最高明之处，不是"把账算清"——是在钱进来之前，先把"怎么议事"的规矩立好。三件套：

① 家族宪法 / 章程（书面化）

写清楚：什么事项需要全体一致？什么70%即可？什么CEO可自主？分红政策？成员退出怎么买回股权？把"争吵"变成"按章程走流程"。

② Owner / Operator 分拆（运营与所有权分离）

家族 = 股东、所有者；CEO = 聘的。

  • Owner 定底线——分红率、负债率、担保白名单；
  • Operator 扛KPI。

Operator 可聘，Owner 不可替代——但 Owner 必须接受董事会和外部董事的绩效刻度。

好处：决策专业化，亲情不被KPI撕。老周的儿子可以当董事长管战略，但日常操盘交给职业CEO+董事会考核。

③ 私董会 / 家族议会

每季度一次：家族成员+外部顾问（律师、税务师、老臣）→ 只谈三件事：

  1. 资产配置底线守没守（堡垒账户≥X%）
  2. 企业重大支出有没有越界
  3. 下一代的培养进度（Step1-3验证到哪了）

不谈感情账，谈的是"系统体检报告"。

深索道这三件套的本质是：把"家人关系"和"钱的决策"解耦。 钱的事按章程走，关系的事按情感走，两个频道分开，才不会互相污染。

国际对照：这不是纸上谈兵

格林格·金这套做法在国际上不是理论。北欧有一家知名的家居企业，创始人在上世纪就把控制权放进了一个非营利基金会结构——章程写死了企业的使命、不得出售、不得分红给家族。家族不"拥有"资产，但保留任命基金会治理成员的通道。

安德路所以经营权可以传，但"把公司当提款机"在章程层面就被焊死了？

格林格·金对。小微主不需要做那么复杂的结构，但可以学三样：

  1. 章程化限制——股东会决议规则写死"分红上限、担保上限、关联交易审批"
  2. 控制权与消费权拆开——家族可享到X%分红，但不得碰资产本体（抵押、抽资）
  3. 外部受托人和保护人——哪怕是国内有限合伙的GP委托、家族委员会加律师作为中立秘书，也能把"父子拉扯"变成"按文件走"

深索道人家传的是"不能败坏的道"，不是"可以花光的钱"。

第七幕 · 三个阀门——"传不传"取决于条件，不取决于年龄

格林格·金但我还是觉得老周最该解决的，是——什么时候交、交多少、什么条件。

深索道对。我管这三个叫"传承阀门"：

阀门一：健康阈值

→ 老周自己身体/认知状态仍在线 → 控盘权不交
→ 只有重大失能（如认知障碍、昏迷等）时，才触发"代行机制"（委托书/信托保护人/董事会决议）

阀门二：能力验证PASS才交

→ 不是"到55岁就交"，是"过了Step1-3答辩"才交
→ 未过 → CEO交给职业经理人，儿子当董事长（监督岗）

阀门三：资产结构就绪才交

→ 堡垒账户/保障金/保险已经就位 → 企业哪怕亏两年，家也不崩
→ 未就绪 → 先补结构，不交舵

安德路所以老周的"再等等"，其实不是拖延——

格林格·金——是他本能地知道：阀门没就绪就交，等于把一艘没装救生艇的船交给一个还没考到驾照的人。

深索道告诉老周一句话：

别传"交班"，传"交系统"。系统就位那一天，舵会自己交出去——不需要煽情。

第七幕·补 · 信心、复利与传承——同一条底层逻辑

安德路深总，我突然想到一个问题——我们之前聊过，信心是复利不中断的核动力，而信心来自一套机制。那传承……是不是也是一套机制？

深索道对。传承不是"交钥匙"，是"交机制"。你传的不应该是"你做了多少年的决策权"，而应该是"一套即使你不在场，也能让钱继续生钱、让家不散架的运行规则"。

格林格·金所以，传承的本质，就是把"你对财富的信心"转化为"系统对财富的约束"。信心来自机制，传承就是把这个机制交到下一代手上。

安德路那如果下一代不信这套机制呢？

深索道那就回到第四幕——能力验证不过，就不交舵。机制的保护对象，不只是财富，也包括下一代自己。

第八幕 · 工具箱引导

深索道前两篇我们讲了家庭税务的四大跑道（日常篇）和合规体检（稽查篇）。今天聊传承——税务合规之后，钱怎么传下去，才是真正的终局。

格林格·金如果你觉得自己家也在"老周状态"，做两件事——

第一，做一张传承清单（10项自查）：

  1. 你家有没有书面的家族/股东协议？
  2. 控制权与收益权有没有分拆？
  3. 企业有没有年度支取上限？
  4. 婚变/继承的股权隔离做了吗？
  5. 第二代有没有过小规模试错验证（不是空口说"我能行"）？
  6. 家风有没有一条硬规矩："财富不用来装饰"？
  7. 堡垒账户 ≥ 家庭年支出的多少个月？
  8. 税务居民身份/CRS申报清了吗？（→ 税务篇）
  9. 有没有家族议会/外部顾问机制？
  10. 阀门条件写下来了吗（健康/能力/结构），还是只存在"我感觉"里？

第二，如果你是出海小微主，额外加三项：

  • 个人担保有没有退出路线图？
  • 海外业务有没有实体化（不再是"国内公司+老板护照"混跑）？
  • 海外回款/税费/汇兑有没有可审计的现金流仪表盘？

格林格·金打开「私家智囊」→ 工具箱 → 「家族传承清单」——13题评估你的传承准备度：

安德路（走到门口，回头）：最后一个问题——如果只能带走一句话？

深索道传钱，三代必败；传资产，一代可守；传机制，才可久。但机制不靠写下来，靠你在世时每一天按它活。

格林格·金信心来自机制，传承就是把这个机制交到下一代手上。

文中的金句

  • 传钱 = 给他鱼。传资产 = 给他渔场。传机制 = 给他"渔场的管理制度+不准拆底线的规矩"。
    → 应用：问自己——你传给下一代的，是鱼、渔场、还是管理制度？
  • 钱会流向能管理它的人；如果你的孩子没学会管理，市场会替你教他——用归零的方式。
    → 应用：不要等"出问题再教"，现在就开始小规模试错训练。
  • 家风的第一条约束函数：家族成员的显性消费增长率 ≤ 企业净利润增长率。
    → 应用：把这条写进家族宪章，每年审计。
  • 把"家人关系"和"钱的决策"解耦——钱的事按章程走，关系的事按情感走。
    → 应用：设立家族议会，不谈感情账，只谈系统体检报告。
  • 别传"交班"，传"交系统"。系统就位那一天，舵会自己交出去。
    → 应用：把精力花在建设系统上，而不是焦虑"什么时候交"。
  • 传钱，三代必败；传资产，一代可守；传机制，才可久。
    → 应用：今天就开始写你的家族传承机制文档。
  • 阀门没就绪就交，等于把一艘没装救生艇的船交给一个还没考到驾照的人。
    → 应用：三个阀门（健康/能力/结构）写下检查清单，每年过一遍。
  • 人家传的是"不能败坏的道"，不是"可以花光的钱"。
    → 应用：价值观教育从今天开始，不是从交班那天开始。
  • 出海小微主的传承第一课不是"接班"，是"解绑"。
    → 应用：检查你的个人担保清单，制定退出路线图。
  • 信心来自机制，传承就是把这个机制交到下一代手上。
    → 应用：让下一代参与机制的设计，而不是被动接受。
